Cara Menghubungkan SIMPATIK Langsung ke Google Spreadsheet Sekolah Anda:

SIMPATIK dapat mengirimkan data pemindaian detik itu juga ke Spreadsheet menggunakan Google Apps Script Web App secara 100% gratis tanpa perlu database berbayar.

1 Langkah Pemasangan di Google Sheet:
  1. Buka file Google Sheets baru di browser.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua teks bawaan, lalu tempel kode skrip di kotak sebelah kanan.
  4. Klik tombol Deploy (Terapkan) → New deployment (Penerapan baru).
  5. Pilih jenis Web app (Aplikasi web).
  6. Ubah Who has access (Siapa yang memiliki akses) menjadi Anyone (Siapa saja).
  7. Klik Deploy, izinkan akses, lalu salin Web App URL yang dihasilkan.
  8. Tempel URL tersebut pada kolom di bawah ini.

Status: Menggunakan simulasi lokal (Belum ada URL live).

2 Kode Google Apps Script (Code.gs)

Salin dan tempelkan kode berikut ke editor Apps Script Anda:

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Buat header otomatis bila sheet masih baru/kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp", "Tipe Event", "NISN", 
        "Nama Siswa", "Kelas", "Keterangan / Alasan", 
        "Petugas", "Status Flag"
      ]);
    }
    
    // Tambahkan baris data presensi baru
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString("id-ID"),
      data.type || "KETERLAMBATAN",
      data.nisn || "-",
      data.nama || "-",
      data.kelas || "-",
      data.reason || "-",
      data.officer || "Agus Suyatno, S.Kom",
      data.status || "NORMAL"
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ 
      status: "success", 
      message: "Data berhasil dicatat di Google Sheets" 
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ 
      status: "error", 
      message: error.toString() 
    })).setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
